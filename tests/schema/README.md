Schemas for local MusicXML validation, with upstream license notices retained.

- musicxml.xsd: https://raw.githubusercontent.com/w3c/musicxml/v4.0/schema/musicxml.xsd
- xml.xsd and xlink.xsd: https://github.com/w3c/musicxml/tree/gh-pages/schema

Validation resolves remote schema imports to these local copies. No schema downloads occur during tests.
